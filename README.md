# AI Dashboard - IPL Dataset

## Project Overview

This project presents an IPL data dashboard using Python, Pandas, and Plotly.

## Dataset

IPL Matches Dataset (2008–2022)

## Features

* Dataset Overview
* Data Cleaning
* KPI Metrics
* 5 Visualizations
* Insights and Findings

## Technologies Used

* Python
* Pandas
* Plotly
* Google Colab

## How to Run

1. Open the Jupyter Notebook.
2. Upload the dataset file.
3. Run all cells sequentially.
4. View the visualizations and insights.
